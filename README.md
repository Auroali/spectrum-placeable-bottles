# Spectrum Placeable Bottles

Spectrum addon that allows placing bottles (and more!) in the world as blocks

## Supported Items

- Infused Beverage
- Chrysocolla
- Jade Wine
- Aqua Regia
- Nectered Viognier
- Evernectar
- Freigeist
- Morchella
- Pure Alcohol
- Suspicious Brew
- Reprise
- Bristle Mead
- Bitter Oils
- Hot Chocolate
- Restoration Tea
- Azalea Tea
- Demon Tea
- Glistering Jelly Tea
- Golden Bristle Tea
- Karak Chai
- Slushslide
- Peach Cream
- Junket

## For datapack creators

Unfortunately, the mod currently does not support adding placeable items via tags. It does however provide three
tags for placeable items: `spectrumplaceablebottles:bottles`, `spectrumplaceablebottles:mugs`,
`spectrumplaceablebottles:placeable`,
for bottles, mugs, and all placeable items.
